# Contributing to EgoLink

We are building the actual device and software in public. This first publication contains the product definition and roadmap; existing source is being prepared for import.

- Open an [issue](https://github.com/getegoai/egolink/issues) for a bug, hardware observation, interface question, or proposed improvement. Include the relevant version, board, conditions, and expected result when available.
- Keep pull requests focused and explain what you changed. State which checks you actually ran; distinguish simulation from real hardware results. Draft PRs are welcome.
- Once code is imported, use the existing build and test instructions for the affected component. Do not assume instructions for one board apply to another revision.
- AI-assisted contributions are welcome. Understand the change, credit its sources, and review its effects before submitting.
- Do not upload credentials, phone numbers, private location traces, or materials you lack permission to share.

Current original documentation contributions use CC BY 4.0. Software and other assets follow the explicit licenses supplied when imported. Community contributions should enter the same product development path as maintainer changes.
