## 迁移

- 专利登记、检索、交底先行 → 开源和专利并行，仅隔离明确保留的具体细节。
- 每个候选需写交底、不申请也需论证 → 仅决定投入申请时整理必要材料。
- 三个案例、一个实验、外部复现为首发要求 → 从一个有价值片段开始，其他随反馈完善。
- 每次全类型清单及数周准备 → 检查实际发布增量，直接进入公开与反馈短循环。
- 严谨被理解为追加前置条件 → 从目标和第一性原理重新界定问题，扩大思考、缩小执行、寻找替代路径。
- 同步北极星、上下文索引和总项目登记；能力事实、商业假设、许可边界继续如实表达。

仅修改策略记忆，保留已有工程验收结果与历史证据日期。初始草案另见
[前一迁移记录](../20261027_open_source_strategy/README.md)。这些快照不是待公开包。
