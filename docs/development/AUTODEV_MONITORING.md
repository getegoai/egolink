# AutoDev Monitoring

AutoDev monitoring is a local development view over task progress, device/session summaries, and validation output.

## Current Rule

Monitoring may summarize local state, but it must not become a product dependency or a substitute for hardware evidence.

## Context Inputs

- `docs/development/AUTODEV.md`
- active task packet under `docs/tasks/active/`
- local session summaries explicitly named by the task
- validation output generated by bounded commands
