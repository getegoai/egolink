# EgoLink 补拍清单

这轮最需要三组真实照片。用手机主摄、窗边散射自然光和一张浅灰或白色哑光纸即可，
不必先搭摄影棚。现有 PCB 局部照片继续用于研发记录，补拍主要解决“看清完整原型”和“理解尺度”。

| 优先级 | 拍什么 | 怎样摆放和拍摄 | 用在哪里 |
|---|---|---|---|
| 1 | **完整原型，45° 斜俯拍** | 主板、电池、天线及当前实际连接的部件放在同一画面；整理线束但保留真实接法。横向 3:2，周围留约 15% 空白，再补一张更宽的 16:9。 | README 的主实物图；X 项目介绍、演示文稿 |
| 2 | **主板正面和背面，各一张** | 镜头正对电路板，两张保持相同方向和比例，丝印朝上可读；手和杂物移出画面，镜头对焦在元件上。 | 文档双面图、关键器件说明 |
| 3 | **尺度与研发现场** | 先拍主板旁放毫米尺的近景，再拍一张正在使用的工作台全景。若已有实际装配外壳，再补手持照；当前没有外壳就拍真实原型。 | 让读者理解体积、装配方式和实际研发过程 |

长边建议至少 2400 像素，发送原图，保留未经裁切的版本。每组拍 3–5 张供挑选即可。
避免数码变焦、闪光灯直打和人像虚化，重点是元件与连接清楚。

拍之前，把模块上的唯一序列号、IMEI、二维码用小纸片挡住或转到背面；板名和版本丝印保留。
若拍到电脑屏幕，使用仓库演示数据或空白终端。只按平时安全的研发方式摆放，不为照片临时接电、改线或演示未经验证的功能。

随图附一句说明就够：**板卡版本 / 拍摄日期 / 连接了哪些部件 / 是否仅摆拍未通电**。
照片到位后，可以直接替换 README 实物主图，并补一张带真实原型的分享卡；不必重做整套设计。
