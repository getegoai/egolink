```markdown
## Ego Link 硬件平台规则

- 当前实现基线是微雪 ESP32-S3-SIM7670G-4G开发板。
- SIM7670G仅用于当前测试，不是已冻结量产模组。
- STM32U5A5、Apollo4、ESP32-P4和Alif B1均为候选平台，未经明确任务不得迁移。
- 产品版主控、GNSS方案、蜂窝模组和摄像头均未冻结。
- 业务层和shared/contracts不得绑定厂商SDK；厂商API只允许出现在平台后端。
- 新平台通过新增后端接入，不修改模型和协议语义。
- 典型守护续航硬目标为48小时，但任何续航结论必须来自整机实测。
- 采购清单是评估参考，不代表硬件已经到货或通过验证。
- 功耗优化不得牺牲SOS、紧急通信、隐私或事件可靠性。
- 每次只完成一个明确的硬件任务，不自行扩展到平台迁移或BOM冻结。
```
