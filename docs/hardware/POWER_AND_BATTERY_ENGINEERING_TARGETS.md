# Ego Link 功耗与电池工程目标

## 1. 续航目标

- 硬目标：典型安全守护不少于 48 小时；
- 进阶目标：轻度使用模式 5—7 天；
- 紧急、高频定位、持续通话或弱信号环境不承诺同等续航；
- 开发板测得的功耗不能直接代表量产整机。

按80%可用容量预留估算：

| 电池 | 48小时平均电流预算 | 7天平均电流预算 |
|---:|---:|---:|
| 1000mAh | 约16.7mA | 约4.8mA |
| 1200mAh | 约20.0mA | 约5.7mA |

这些是整机平均电流上限，不是主控目标。4G、GNSS、摄像头、扬声器和弱网重试通常比微模型推理更耗电。

## 2. 功耗域

```text
常开/低功耗域
├─ RTC
├─ SOS按键
├─ 低功耗IMU
├─ 必要的音频门控
└─ MCU低功耗状态

按需域
├─ 高性能CPU / AI加速
├─ GNSS
├─ 4G数据连接
├─ 摄像头
├─ 音频功放
├─ 屏幕
└─ 存储写入

紧急域
└─ 以安全为先，可突破常规功耗预算
```

## 3. 固件必须提供的测量能力

- 每个功耗状态的进入、退出时间戳；
- 4G上电、注册、上传、DRX/睡眠和关机事件；
- GNSS启动、首次定位、关闭事件；
- 模型推理开始、结束和模型版本；
- 音频、摄像头和存储写入窗口；
- 电池电压、电量、充电状态和复位原因；
- 每个场景的统计计数和累计时长；
- 可通过GPIO或串口输出测量标记，便于与功耗仪波形对齐。

## 4. 测试层级

### A. 组件基线

- MCU深睡、守护、活跃；
- IMU采集；
- MotionNet单次推理；
- AudioGate持续运行；
- GNSS一次冷/热启动；
- 4G注册、一次上报、一次语音通话；
- 拍照和上传一张图片。

### B. 标准场景

- 1小时安静守护；
- 周期心跳；
- 周期定位；
- 事件触发、询问用户、上传摘要；
- 网络断开与重连；
- 低信号环境；
- 一次紧急升级。

### C. 长时测试

- 48小时典型守护，至少三轮；
- 72小时观察；
- 不同运营商、不同信号环境；
- 记录失败、重启、丢事件、温升和容量误差。

## 5. 仪器使用

- 已有 PPK2：适合主控、传感器和较低电流域；
- 4G峰值和长时电池仿真若超出PPK2能力，使用支持更高峰值的功耗分析仪；
- 所有测试保存原始波形、固件版本、配置、SIM卡/运营商、信号和环境说明。

## 6. Codex约束

- 不得依据芯片数据手册宣称整机达到两天或七天；
- 不得通过降低SOS可靠性、禁用必要定位或关闭来电能力来“优化”续航；
- 功耗优化必须同时通过功能和安全测试；
- 所有功耗配置必须可追溯、可回滚、可按模式切换。
