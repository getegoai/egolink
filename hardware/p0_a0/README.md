# EgoLink P0 A0 Conditional Design Pack

Pack revision: `HW021-C0.1`

State: `conditional_candidate_intake`

Hardware evidence: `NOT_RUN`

This directory holds the first reviewable HW-021 intake for an integrated
`Reliable Location + Ego Call + SOS` prototype. It is deliberately earlier
than schematic capture: exact public candidates are recorded where an official
manufacturer source exists, while unresolved ordering suffixes, electrical
budgets and product choices stay explicit.

## Pack Contents

- [source matrix](HW021_C0_1_SOURCE_MATRIX.md): exact candidate/orderable
  identities, official source revisions and source gaps;
- [interface budgets](HW021_C0_1_INTERFACE_BUDGETS.md): conditional ownership,
  bearer/audio/storage/power/RF constraints and test-point plan;
- [review checklist](HW021_C0_1_REVIEW_CHECKLIST.md): independent EE/RF/audio,
  privacy, compliance and release-blocker checklist.

No schematic, layout, final BOM/AVL, stack-up, fabrication output or selected
production hardware exists in this pack. It does not authorize procurement,
fabrication, assembly, flashing, SIM traffic, RF transmission or power-up.
