# EgoSkin/Cradle 自定义机械接口草案
接口状态：**PREVIEW / 未冻结**　基线：C-ME-0.1

## 责任边界
EgoCore承担电子和主防护；Cradle承担佩戴拉力、限转和保持；EgoSkin承担外观。后两者可合成一件。用户修改不进入核心干腔，不更改密封压缩、相机安装或电芯约束。

## 首轮需由CAD输出的公共几何
1. 核心实际配合外表面和基准，不是只给长宽厚方盒。
2. 允许接触/承力的表面，锁止方向和防错装标记；允许变形和限位范围。
3. 完整相机视场/光轴容差体、扬声器/麦克风声道保护体、压力膜保护区、按键行程/手指接近空间。
4. LTE/GNSS/2.4GHz的材料/金属限制区域，USB插头拔插和排水体，服务开盖路径。
5. 最大外附件厚度/质量与载荷要求；未取得数值前标TBD，不用统一2mm假定代替RF和承力验证。

## 首轮外附件
优先一个成人台架或衣夹/挂件载体，不铺开全部人群。验证拆装、倒置保持、挂绳拉力路径、相机朝向与按键不被压住。芯舱退出方向与载体受力方向尽量分开，释放件不得以刺入电池或撕裂核心作为失败方式。

夹具/挂绳防脱与遇缠绕时释放属于不同目标；儿童版和宠物版分别做适用性评估，不把成人载体直接缩小后发布。

## 材料与打印
初轮限未经导电填充的受控塑料。金属、碳纤维、石墨、金属漆、电镀及未知导电颜料不得覆盖未验证的RF区。打印方向、层高、工艺、材料品牌/批次、配合校准试条记录在具体附件版本里。

通过尺寸检查仅表示装得上；外壳仍需确认相机无遮挡、声音没有显著被挡、网络/GNSS性能、排水、长期保持和皮肤接触适用性。未经验证不得沿用核心的IP/RF/安全声明。

## 版本兼容
首轮文件名包含`I0.1_PREVIEW`。坐标、锁止位置或核心包络变化时更新接口修订和配套壳版本。真正稳定后再发布公开STEP/STL/3MF与参考壳，不将此包自动公开。
