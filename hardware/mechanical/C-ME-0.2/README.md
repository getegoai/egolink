# C-ME-0.2｜现板装配研究与外观选项保留

日期：2026-10-10。状态：**装配关系提案，待实测；不是 CAD 装配、加工图或硬件验证结果。**

## 本轮结论

先做能真实装下现板和配件的工程样机，再由实装结果反推小型化 PCB。
建议先评审 **A：GNSS 端部分仓＋主板与电池背叠**；用同一批实测器件比较
**B：GNSS 端部分仓＋电池局部错位**。A 少依赖现板改动，B 用更大的平面面积
换取降低局部堆叠的可能性。两者尚未证明可装配；不预先承诺缩小比例。

本轮保留烟熏玻璃饰品风与白色／红色 SOS 两个外观方向。首版继续无屏。
不因理想效果图而压缩电池余量、天线空间、密封结构和装配间隙。

## 两种布局怎么比较

| 项目 | A：背叠，首台样机优先评审 | B：局部错位，减薄候选 |
| --- | --- | --- |
| GNSS | 独立放在主板端部的候选区域 | 同样分仓，不在主板＋电池之上再叠一层 |
| 电池 | 独立托盘置于主板背侧 | 向主板低器件区或板外延伸，避开较高器件的投影 |
| 代价 | 较高模组／卡座可能决定电池离板距离，机身较厚 | 通常增加长度或宽度，需验证剩余重叠区及出线空间 |
| 适用条件 | 接插件、发热和独立固定空间可满足 | 真实高度地图证明有可用区域，所选电池外形允许错位 |
| 失败时处理 | 增大工程壳，不强压电池或弯折 PCB | 回到 A；平面错位不成立就不能宣称减薄 |

图中的器件位置仅用于解释关系，**不是从照片重建的元件坐标**。特别是
“主板低器件区”尚未测量。A、B 的板朝向也未冻结：由 USB／卡座／FPC 的实际
位置、镜头位置和装配工具可达性共同确定，不能只为电池平整而随意翻板。

外壳厚度应按 **各位置实际占用高度的最大值** 计算，再加入壳体、托架、
制造公差和相应器件余量。主板与电池重叠处至少要计入：

`前侧空间 + 主板正面器件 + PCB + 背面器件 + 隔离/支承 + 电池最大包络及余量 + 后盖`

镜头、声腔等只在其真实投影重叠处增加高度。GNSS 分仓后与主板／电池区域
比较谁更厚，而不是在整个产品厚度上再加一层 GNSS。密封台阶、螺柱、接插件
配合件和线缆转弯同样进入三维碰撞检查。

## 零件如何固定与连接

| 部件 | 建议装配方式 | 现板必须确认的条件 |
| --- | --- | --- |
| 主板 | 可拆内托架承托安全板边；用限位台阶与压片／卡扣约束，已存在的合格机械孔才可用于螺钉 | 板边无器件、走线与焊点受压；夹紧力与跌落强度待验证；不能靠 USB、FPC 或排针承重 |
| GNSS | 端部独立定位座，保留插拔与线束应力释放；固定接收板或整套模块 | 若带陶瓷天线，按板＋天线＋接插件整体计尺寸；若分体，分别定位接收板和天线 |
| 电池 Pack | 后侧独立托盘，绝缘隔板、合适保持方式及可维修出线；紧固载荷绕过电芯 | 包含保护板、极耳、包膜、线材、连接器、供应商规定的最大厚度及膨胀空间；不得被卡座／焊点／螺钉顶压 |
| 摄像头 | 固定于前部功能支架，独立控制光轴、窗口距离与视场；FPC 只传信号 | 先确认现板 FPC 接口和相机料号；有足够弯折与装拆余量，无锐边夹线 |
| 扬声器 | 独立定位、周边密封、明确后腔和出声通道 | 不把剩余电池空隙当成已设计的声腔；检查声音路径与实际器件匹配 |
| 麦克风 | 依实际数量分别预留短导音路径与膜／垫片安装面 | 单／双麦及现板实现未知；隔开扬声器内部串音路径，不凭外壳小孔推断已有麦克风 |
| SOS 与反馈件 | 按键由壳体限位与承力，振动件／导光件有独立定位 | 现有 KEY／BOOT／P0 不等于产品 SOS；推杆需核对行程、方向和支承；移到侧面可能需要下一版 PCB 或按键小板 |
| LTE／Wi-Fi 天线 | 周边候选区域布置，馈线固定并留弯折、插拔空间 | 地平面、净空、邻近金属与线缆走向服从具体天线资料；不能一概要求整个区域无铜 |
| USB／卡座 | 首轮沿用真实端口位置，预留插头、插卡和维修操作空间 | 现板 USB 焊在主板上，不能在图中擅自变成独立密封小板；卡座的实际类型与服务路径待确认 |

GNSS 端仓只是布局候选，不保证佩戴时朝天。腕戴、胸夹和挂坠的姿态与人体遮挡
不同，须连同 LTE 发射干扰评估。具体天线的地平面与周围结构会影响表现，
不能仅凭“放到最上面”判断定位效果。[u-blox 天线应用说明](https://content.u-blox.com/sites/default/files/products/documents/GNSS-Antennas_AppNote_(UBX-15030289).pdf)

主板热点、电池和贴身后盖需要一起评估温升；绝缘隔板不等于散热设计。
若改用更厚隔热件，也要重新核算厚度与热路，不能把温度问题隐藏在结构图里。

## 外壳、防水与佩戴件

建议保留“前部功能壳／支架＋可拆电子托架＋电池托盘＋后盖”的维修路径。
产品版核心舱目标为独立密封：后盖连续密封圈和压缩限位、窗口独立粘接密封、
声学膜和按键密封分别设计；螺钉位于密封路径之外或使用与外界隔离的盲孔结构。
挂点、背夹与腕带载荷传给承力壳／Cradle，不通过电池、PCB 或装饰面板。

现板首轮可先做便于观察与插拔的**干态装配样壳**，这不满足产品防水放行。
板载 USB 的暴露口、卡座服务路径与壳体穿透必须逐项解决后，才能进入密封试样。
生产目标的无塞 USB-C 湿区方案仍需单独结构／电气评审，不用普通开孔代替。
声学防护的效果取决于膜、安装位置、通道、壳体和密封组合，膜材标签不能替代
整机验证。[Gore 声学系统设计说明](https://www.gore.com/resources/designing-acoustic-system-gore-acoustic-vents-gated)

烟熏外观可保留深色面板与低存在感镜头的视觉语言；光学窗口的透过率、反射、
遮光与视场需单独验证，不能默认在镜头前覆盖同样深色的装饰层。
金属感边框的材质／镀层与天线空间也未冻结。

**两版外观不是已证明可互换的 EgoSkin。** 白色版的正面 SOS／喇叭与烟熏版的
侧键／底部出声／角落镜头不同，可能需要不同前功能壳、支架和柔性连接。
共用电子托架、后盖及承力附件接口是后续设计目标，不是本轮结论。
腕戴效果图仅保留形态可能性；应先做实重手感模型，比较厚度、重心、腕部活动、
镜头方向和 SOS 可达性，再决定是否适合腕戴首发。

## 建议装配顺序

1. 工程团队提供去工艺边后的 PCB 外形与两面器件高度，先用模型／未供电实物
   检查托架、卡座、插头和工具空间；定位基准先固定，避免临时胶粘堆叠。
2. 前功能壳预装镜头窗口、声学组件及其支架／密封件；相机和声学零件各自定位。
3. 主板装入托架。先连接后续会被电池遮挡的 FPC 与线束，检查连接器锁扣可达。
4. 固定 GNSS 和天线，整理馈线及信号线到专用走线区域，避开螺柱、密封圈和锐边。
5. 电池 Pack 装入独立托盘，留断电／维修路径。首次碰撞与夹线检查优先使用
   电池外形模型；真实电池接入和通电按操作人员授权的硬件流程执行。
6. 合盖检查各处间隙、按键行程及反复拆装；不得靠压紧后盖强行消除干涉。
7. 几何成立后，分别安排带壳 RF／GNSS、温升／功耗、声学、跌落／附件拉力及
   密封样件试验。每项证据记录样板、固件／镜像、连接路径、时间和文件位置。
